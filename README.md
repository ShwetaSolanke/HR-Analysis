# HR-Analysis
# HR Analytics Tableau Dashboard

## 📊 Project Overview

This project showcases an **HR Analytics Dashboard built using Tableau**, designed to analyze key human resource metrics and provide actionable insights for decision-making. The dashboard helps understand workforce trends, employee attrition, and overall HR performance using interactive visualizations.

The project demonstrates practical skills in **data cleaning, data visualization, and business analytics**, making it suitable for HR, analytics, and data roles.

---

## 🗂️ Dataset

* **File Name:** HR Data.xlsx
* **Type:** Structured HR dataset
* **Contents Include:**

  * Employee demographics
  * Job roles and departments
  * Attrition status
  * Salary and experience-related fields
  * Performance and workforce indicators

The dataset was cleaned and prepared before being imported into Tableau for analysis.

---

## 📈 Dashboard Features

The Tableau dashboard provides insights such as:

* Overall employee distribution
* Attrition analysis across departments and job roles
* Workforce trends based on age, gender, and experience
* Comparative analysis of key HR metrics
* Interactive filters for deeper exploration

The dashboard is designed to be **user-friendly and interactive**, enabling stakeholders to quickly identify patterns and problem areas.
